Google favicon findings
The live homepage supplies only /favicon.svg, a generic serif H on teal. The file
returns HTTP 200 and image/svg+xml on both apex and www hosts. robots.txt allows
crawling. HTTP redirects to HTTPS. No definitive Search Console diagnosis was made.
Google's current documentation lists BMP, GIF, ICO, PNG, JPEG, PPM and TIFF as
supported favicon formats; the current SVG-only setup lacks a listed format.
After the mark is selected, supply a stable /favicon.png above 48px (96px square),
/favicon.ico fallbacks and /apple-touch-icon.png, with homepage link elements.
The reusable npm run assets:brand command prepares those files plus a 512px icon
from public/favicon.svg. Replace the placeholder source with the selected vector
before running it. No new mark or favicon links have been deployed in this exploration.
Keep SVG for modern browser rendering. Verify actual image bodies, MIME types,
square dimensions and accessible URLs on the deployed site. Google recrawling can
take days to weeks, and display is not guaranteed. The old indexed title/snippet
in the owner's screenshot is also older than the current live HTML.
