HEWGE — IDENTITY EXPLORATION
14 October 2026

Status: exploration, not an approved identity. The current direction is the name
HEWGE as an imposing editorial masthead. The owner described the brand as
newsworthy, punchy, huge, powerful and important, with the front page of a
newspaper and "read all about it" as references. The name itself should carry
that force through scale, distinctive lettering and confident editorial layout.

masthead-direction.png is the current generated concept: a large, tightly spaced
heavy editorial serif wordmark, shown as a masthead, teal poster and garment label.
Generated with the built-in image-generation tool; prompt: masthead-prompt.txt.
The newspaper reference is about presence and authority, not reproducing an
existing publication's logo. Keep the customer-facing voice understated; visual
impact does not require claims about hype, exclusivity or importance.

The owner rejected the proposed 1/1 edition mark as "boring and too literal",
then rejected the FOLD / CUT / TRACE abstract symbols. Those are superseded
explorations, not directions to apply to the live site.

abstract-directions.png records the earlier FOLD, CUT and TRACE explorations.
Generated with the built-in image-generation tool. Prompt: concept-prompt.txt.
These are raster concepts, not production artwork or trademark clearance.
Once the wordmark is settled, redraw as a clean vector, refine spacing and derive
a small-size icon from that identity. Verify the icon at 16/24/32 pixels, in a
circular crop, and in a single-colour physical stamp. Do not default to a random H.
Use exact brand teal #00FEEF in production; generated concept colours are approximate.
Sentence full stops remain solid #00FEED in production. These raster mockups are
directional and have not replaced the website, app icons or production assets.

Google favicon findings
The live homepage supplies only /favicon.svg, a generic serif H on teal. The file
returns HTTP 200 and image/svg+xml on both apex and www hosts. robots.txt allows
crawling. HTTP redirects to HTTPS. No definitive Search Console diagnosis was made.
Google's current documentation lists BMP, GIF, ICO, PNG, JPEG, PPM and TIFF as
supported favicon formats; the current SVG-only setup lacks a listed format.
After the mark is selected, supply a stable /favicon.png above 48px (96px square),
/favicon.ico fallbacks and /apple-touch-icon.png, with homepage link elements.
The reusable npm run assets:brand command prepares those files plus a 512px icon
from public/favicon.svg. Replace the placeholder source with the selected vector
before running it. No new mark or favicon links have been deployed in this exploration.
Keep SVG for modern browser rendering. Verify actual image bodies, MIME types,
square dimensions and accessible URLs on the deployed site. Google recrawling can
take days to weeks, and display is not guaranteed. The old indexed title/snippet
in the owner's screenshot is also older than the current live HTML.
